# WME Relock
Fork of the original WME LevelReset script, now renamed to WME Relock.

Differences from the original one:
- Ukraine (and other countries) locking rules support;
- Rules are loading from external google sheets file;
- Rules can be scoped to cities (streets and POIs);
- Added support for Narrow and pedestrian streets, and later to all supported types;
- Beside streets checks added support for:
  - POIs
- Options are saved between sessions;
- Script is migrated to the official Waze SDK;
- removed dependency on jQuery.

Update Rules: If you want add your country, you should PM to @Sapozhnik (Waze, Ukraine Community)
